# 雲起時 金口訣

金口訣七步起課，單檔網頁、手機可直接使用。

## 網址

https://hungpinoffice-afk.github.io/yunqi-jinkou/

## 功能

- 七步起課：定四柱 → 取地分 → 定月將（月建六合）→ 定貴神 → 定將神 → 定人元（五子元遁）→ 定用爻
- 兩種輸入：西曆年月日時（預設當下時刻）／四柱干支直接輸入
- 每列六項資訊：旬空（日旬空・四大空亡）、陰陽（＋／−）、五行、內旺衰、外旺衰、神煞
- 30 種神煞掃描，並分吉神／凶煞配色
- 24 節氣：點標題列節氣膠囊展開全年，干支輸入時依年柱推算
- 晝夜貴人自動判斷（05:00–17:00 用晝貴）

## 手機使用

1. 用瀏覽器開上面的網址
2. iPhone（Safari）：分享 → 加入主畫面；Android（Chrome）：⋮ → 安裝應用程式／加到主畫面
3. 加到主畫面後就像 App 一樣全螢幕開啟，且**離線也能用**（Service Worker 已快取）

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 主程式（單檔，無任何外部依賴） |
| `manifest.webmanifest` | PWA 設定 |
| `sw.js` | 離線快取（先網路、後快取，線上永遠拿最新版） |
| `icon-*.png` / `favicon.svg` | 主畫面圖示 |

更新方式：改完 `index.html` 直接 commit + push，重新整理即生效（不需改 `sw.js` 版本號）。
